One word for the whole internet: **unpaid**.

The whole internet runs on unpaid work — billions of hours of posts, memes,
comments, moderation and edits, all for free, while a handful of companies
profit. Funny on its own, true of the internet as a whole, surprising, and it
lands in one beat: six letters.

## Run

```sh
node main.ts   # writes /output/entry.txt (or $MAKEFUN_OUTPUT_DIR/entry.txt)
```
